# FolderMate 1.1.1

- **Fix, typing a new note's name:** with "Reveal the open note" on, the cursor could jump out of a new note's title into the file explorer while you typed its name (GitHub issue #1). FolderMate now reveals the note the same way Obsidian's own "Auto-reveal current file" does: it expands the folders and scrolls the note into view, but never moves focus to the explorer.
